# Agent Note: 显式的问题选项继续操作

Status: implemented

[English](2026-09-20-question-option-quick-action.md) | 中文

## Problem

用户需要无需移动到底部即可回答单选题，同时保留在发送前检查或更改选项的机会。

## Decision

前面的单选题点击选项即前进。最后一题的选项正文只修改选择，与正文并列的「提交」按钮则选择该项并在检查全部答案后提交。这个文字按钮带底色，在选项悬浮或聚焦时显示，不支持悬浮的设备始终显示。多选、自由文本和计划审批保留现有提交控件。

## Alternatives considered

**双击选项**不易发现，并混合了选择和提交。有标签且支持键盘的按钮能明确表达操作。

**每题都提供箭头**会在最后一题之前增加不必要的操作。最后一题使用「提交」文字能直接说明操作。

**每次选择立即提交**会失去修改答案的机会，也无法表达多选答案何时完成。

## Consequences

预留操作空间避免文字移动。并列按钮避免交互元素嵌套。提交使用刚点击选项的新草稿，拒绝不完整的答案组，在等待期间阻止重复发送，并在失败时保留草稿。宿主答案格式和模型工具不变。
