# Agent Note: 全窗口设置页面

Status: implemented

[English](2026-09-04-full-window-settings-page.md) | 中文

## 问题

居中的设置弹窗把各功能所属页面限制在狭窄的内容栏中。表格等宽内容会失去可读列宽，纵向内容还需要与弹窗框架争夺空间。

## 决策

宿主选择 `presentation: page` 时，设置外壳展示全窗口页面，其中导航栏宽度固定，内容栏占用剩余宽度。可见的**返回应用**操作与 Esc 会回到应用，点击页面背景不会触发导航。设置分区继续使用既有 slot 账本，并继续接收同一个 `close()` 操作以支持离开设置的流程。

[宿主展示选择决策](../architecture/2026-09-06-host-owned-ui-presentation.zh.md) 将此布局作为可选项，并保留通用弹窗；页面布局与分区归属保持不变。

## 考虑过的替代方案

**保留居中弹窗并增加最大宽度。** 该方案保留了模态展示，但所有分区仍受视口边距和弹窗几何尺寸约束。

**仅让宽内容功能页面突破弹窗宽度。** 该方案会让布局行为依赖具体功能，并迫使插件越过其不拥有的设置外壳。

## 后果

所有设置分区都获得稳定的横向空间和统一返回路径，且注册 API 不变。页面会暂时替换应用内容，因此不再提供点击外部关闭或紧凑弹窗上下文。
