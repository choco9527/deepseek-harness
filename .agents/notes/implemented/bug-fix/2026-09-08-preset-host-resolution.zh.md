# Agent Note: 预设宿主解析

Status: implemented

[English](2026-09-08-preset-host-resolution.md) | 中文

## 问题

当 Profile 没有实体依赖树时，预设发现可能拒绝宿主解析器提供的包。

## 决策

发现过程保留已安装包检查，在未找到时使用支持父路径的 CommonJS 解析。解析不执行插件代码。核心不包含产品名称或归档格式特判。

## 考虑过的替代方案

**发现时导入插件。** 这会在列出预设时执行副作用。**禁用健康检查。** 这会放行真正缺失的插件。**把全部宿主依赖复制到 Profile 旁。** 这会重复宿主已安装的运行时。

## 影响

测试同时覆盖宿主解析、缺失包拒绝和解析器恢复。只有 ESM 钩子而没有对应 CommonJS 解析器的宿主仍不受支持。实体包存在仍是保守检查，不能证明挂载一定成功。
