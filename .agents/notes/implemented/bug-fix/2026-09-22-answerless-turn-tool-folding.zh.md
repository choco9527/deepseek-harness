# Agent Note: 无最终正文的轮次工具折叠

Status: implemented

[English](2026-09-22-answerless-turn-tool-folding.md) | 中文

## Problem

停止和失败的轮次可能在没有最终 Assistant 回复的情况下结束。应用控制的折叠若要求存在该回复，就会让工具行和上下文行在轮次关闭后仍保持展开，与应用的固定展示策略不符。

## Decision

[应用控制的策略](../feature/2026-09-14-application-owned-tool-folding.zh.md)依据轮次已关闭状态折叠，不再要求最终正文。没有最终正文的过程在记录包含轮次起点时从该起点开始，覆盖首个工具之前的上下文条目。会话作用域 UI store 用 null 正文步骤记录其手动展开状态；后续出现的编号正文步骤仍使用独立的展开 generation。

仅工具行和上下文行收起。Assistant 正文、独立交互卡片、错误和系统提示词保持可见。进行中的轮次以及上游标准/紧凑行为不变。不改写 Session 事件、模型请求或持久化数据。

## Alternatives considered

- 伪造最终回复会歪曲已记录的对话。
- 全局移除最终正文要求会改变上游紧凑模式行为。
- 隐藏整个轮次会隐藏交互卡片和失败证据。

## Consequences

已有的无最终正文历史无需迁移即可获得相同的默认收起行为。回归覆盖须包含停止、失败和正常结束但无最终正文的轮次、工具之前的上下文、手动展开、历史重新加载、独立交互卡片以及未改变的上游模式。
